# Backend

FastAPI, извлечение документов, агент OpenAI и технический интерфейс `static/demo.html`. Команды выполняются из корня: см. [README](../README.md).

- `app.py`: HTTP, очередь, покрытие, ошибки.
- `extraction.py`: цитаты и адреса DOCX/XLSX/PDF/MD/TXT.
- `agent.py`: инструменты и проверка ссылок.
- `models.py`: схемы ответов HTTP и модели.
- `storage.py`: локальные задания и восстановление состояния.
- `config.py`: ключ из корневого `.env`, лимиты.
- `tests/`: проверки без сетевых запросов.

Один worker. Публичный многопользовательский сервер не входит в эту версию.
