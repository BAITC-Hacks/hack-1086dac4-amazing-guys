# Проверка Docker-упаковки — 23 сентября 2026

Проверено локально на Windows с Docker Desktop, Linux Engine 29.1.3 и Compose 5.0.1.
Это проверка упаковки и описанных сценариев, не подтверждение публичной безопасности
или универсальной точности модели. Инструкция: [deploy/README.md](../deploy/README.md).

## Выполнено

- `docker compose up -d --build --wait`: оба сервиса healthy.
- `docker compose --profile checks run --build --rm backend-tests`: 102 passed.
- Production-сборка frontend прошла внутри многоэтапного Dockerfile.
- `/api/health` доступен через опубликованный порт 8080; отдельный backend-порт
  на хост не опубликован. API-запросы браузера идут через тот же origin.
- Проверены UID контейнеров: backend 10001, web 101. В backend-образе без
  runtime-монтирования нет `.env`, пользовательских `uploads/` и `outputs/`.
- Настоящий анализ короткой пары из `fixtures/quick-check/` завершился:
  `8f65d966d6154db18dc3c3643435fd25`, одно `possible_duplication`, 4 модельных
  запроса, 12083 входных / 3537 выходных токенов, оценочно $0.0029768.
  Ответ модели не подменялся. Эталон из README в модель не отправлялся.
- В браузере проверены загрузка, статус, отчёт, получение источников, сравнение
  цитат рядом, сохранение и повторное открытие локального решения сотрудника.
  Повтор с тем же Idempotency-Key вернул существующий анализ, без нового вызова модели.

Остальные автоматические проверки общей версии: 35 браузерных сценариев ранее,
после изменения времени ожидания — 4 затронутых проверки и production-сборка.
Повтор всей браузерной серии на каждой редакционной правке не выполнялся.

## Границы

- Healthcheck не вызывает модель и не подтверждает ключ, кредит или связь с провайдером.
- Незавершённые задания не переживают перезапуск backend; завершённые JSON хранятся
  в отдельном томе. Не останавливайте нужный активный анализ.
- Native-результаты и решения браузера другого origin в Docker не переносятся.
- На большой DOCX-паре один последующий запуск завершился ошибкой проверки
  дословных цитат. Docker эту модельную нестабильность не устраняет; подробности
  в [журнале интеграции](INTEGRATION_RESULTS.md).
- Независимый запуск товарищем и официальная сдача не подтверждены этим документом.
