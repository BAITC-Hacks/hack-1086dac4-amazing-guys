## Границы

- Healthcheck не вызывает модель и не подтверждает ключ, кредит или связь с провайдером.
- Незавершённые задания не переживают перезапуск backend; завершённые JSON хранятся
  в отдельном томе. Не останавливайте нужный активный анализ.
- Native-результаты и решения браузера другого origin в Docker не переносятся.
- На большой DOCX-паре один последующий запуск завершился ошибкой проверки
  дословных цитат. Docker эту модельную нестабильность не устраняет; подробности
  в [журнале интеграции](INTEGRATION_RESULTS.md).
- Независимый запуск товарищем и официальная сдача не подтверждены этим документом.
