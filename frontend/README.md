# Контур — frontend

Рабочий интерфейс анализа организационных изменений для Amazing Guys / HackAlem.
Код находится в `frontend/` общей ветки `main`. Backend не изменяется этим модулем.

## Запуск без backend

Требуется Node.js **22.12+** (проверено на 24.21) и npm.
Из корня репозитория:

```sh
cd frontend
npm ci
npm run dev
```

Откройте **http://127.0.0.1:5173** и нажмите **«Открыть пример»**.
Можно сразу выбрать любой раздел слева: в деморежиме он откроется с авторским
примером, без предварительной загрузки или запуска анализа. В режиме сервера,
пока отчёт не получен, раздел объясняет, какие данные нужны, и предлагает
загрузку документов или явный переход к демопримеру.
Ключи и запущенный Python не нужны. Шрифт Golos Text поставляется локально
через npm; внешние CDN и аналитика не используются.

Деморежим показывает **заранее подготовленный авторский пример**, а не результат AI.
Документы вымышленной компании взяты из `../fixtures/org-review/`.
Выбранные пользовательские файлы в деморежиме не отправляются и не анализируются.
После перезагрузки вкладки выбор файлов и отчёт сбрасываются.

## Что работает

- Два комплекта файлов: выбор, перетаскивание, удаление, проверка формата,
  пустых файлов, лимита 5 файлов на комплект и 5 МиБ на файл.
- Обзор с показателями, рассчитанными из текущего отчёта.
- Матрица функций с поиском и фильтром статуса, связи один-к-многим.
- Подразделения: сохранение, переименование, создание, удаление и другие статусы r1.
- Полный реестр функций обоих комплектов, включая не вошедшие в соответствия.
- Замечания с поиском и фильтром типа, осторожные формулировки и охват проверки.
- Панель источников: версия, адрес фрагмента, точная цитата, контекст и копирование.
- Список документов, предупреждения чтения и отдельное состояние неполного покрытия.
- Заключение, рекомендации с источниками, скачивание текущего отчёта в JSON.
- Адаптивная навигация, выдвижная панель источников, клавиатурный фокус,
  Escape для закрытия источников и поддержка reduced motion.
- Короткие переходы между разделами и вкладками, плавное открытие и закрытие
  источников, подсветка выбранной записи в таблицах и обзоре. Во время загрузки
  источников показаны скелетоны; готовые данные открываются без искусственной паузы.
  Быстрое переключение отменяет старые запросы, после закрытия фокус возвращается
  к последней выбранной записи. Системная настройка уменьшения движения отключает эффекты.
- Четыре демосценария: полный пример, неполное покрытие, ошибка, пустой результат.
  Сценарий выбирается в раскрывающемся блоке на карточке примера.

Демонстрационный текст и цитаты находятся в `src/demo-data.json`.
Исходные Markdown-файлы — в `public/demo/`. Автоматическая проверка сверяет
каждую цитату с исходником. Эталонная разметка применяется **только для UI-демо**,
никогда не отправляется модели или API.

## Подключение к backend

Режим «Сервер» выбирается внизу боковой панели. По умолчанию клиент использует
`http://127.0.0.1:8000`, согласно `../API_CONTRACT.md` (r1).

Для другого адреса создайте `frontend/.env.local` по примеру `.env.example`:

```dotenv
VITE_API_BASE_URL=http://127.0.0.1:8000
```

После изменения переменной перезапустите Vite. Любая `VITE_*` переменная публична:
**не добавляйте туда ключи модели, пароли или токены**.

1. Капитан запускает backend по его README и настраивает модель.
2. В интерфейсе включите «Сервер», выберите оба комплекта и нажмите «Сравнить документы».
3. Клиент отправит multipart `before_files` / `after_files`, затем будет читать статус,
   отчёт и источники. Поддерживаемые расширения: PDF, DOCX, XLSX, TXT, MD.
   DOC/XLS нужно предварительно преобразовать; реальную читаемость проверяет сервер.
4. JSON-ответы проверяются схемами Zod, синхронизированными с `backend/models.py`.
   Неожиданный формат показывается как ошибка, а не успешный отчёт.

Повтор после сетевой ошибки использует прежний `Idempotency-Key` и те же файлы.
После явного `failed` повтор создаёт новый анализ. Клиент не выполняет скрытых
повторных POST. Polling ограничен десятью минутами; сетевой запрос — 30 секундами.
«Остановить ожидание» прекращает запросы браузера, **не отменяет задачу на сервере**:
контракт r1 не содержит endpoint отмены. Повтор продолжает ожидание известного анализа.

Подключение с HTTP-подменами проверено тестами. Результаты совместного запуска
с настоящим backend/AI — в `../docs/INTEGRATION_RESULTS.md`. Backend разрешает
локальные origins 5173 и 4173 по умолчанию. При сборке для HTTPS адрес API тоже должен быть HTTPS.

## Сборка и проверки

```sh
npm run build
npm run preview
```

Production preview: http://127.0.0.1:4173.
Статические файлы собираются в `dist/` (не коммитятся).

Браузерные проверки:

```sh
npx playwright install chromium
npm test
```

Или с уже установленным Google Chrome, без скачивания Chromium:

```sh
PLAYWRIGHT_CHANNEL=chrome npm test
```

Тесты запускают/используют локальный Vite на 5173. API перехватывается Playwright:
реальные файлы и запросы модели на сервер не уходят. Проверяются основной сценарий,
цитаты, поиск, фильтры, выгрузка, загрузка и ограничения файлов, неполнота, сбои,
пустой ответ, multipart и polling, идемпотентность, ошибочные схемы, безопасный текст,
мобильный экран и автоматическая доступность (axe). Отдельно проверяются медленные
источники и повтор после ошибки, отмена устаревшего ответа, быстрое переключение
во время закрытия панели, возврат фокуса и reduced motion.

```sh
npm run format
```

## Структура

- `src/App.tsx` — экраны и управление сценарием; UploadBox и Inspector.
- `src/styles.css` — адаптивное оформление, состояния и эффекты.
- `src/contracts.ts` — схемы r1, типы и подписи статусов.
- `src/api.ts` — HTTP-клиент, ошибки, лимиты файлов.
- `src/demo.ts` / `src/demo-data.json` — изолированные авторские сценарии.
- `tests/frontend.spec.ts` — независимые браузерные проверки.

## Границы версии

Нет сохранения проверки сотрудником, чата, истории анализов между сессиями,
редактирования документов и экспорта PDF: эти операции не входят в текущий r1.
Для API-источника отображаются предоставленные цитата и контекст; полного PDF-viewer
и скачивания оригинала нет, поскольку контракт не предоставляет оригинальный файл.
Для авторского примера доступен исходный Markdown. Кнопки неподдерживаемых операций
не имитируются. Демонстрационная анимация не выдаётся за реальные вызовы инструментов.

Дизайн и код подготовлены с Codex. Используются React, TypeScript, Vite, Zod,
Lucide (иконки), Golos Text; тесты — Playwright и axe. ImageGen-макет послужил
визуальным ориентиром; сгенерированные цитаты из него в приложение не перенесены.

Результаты проверки и скриншоты: [docs/VERIFICATION.md](docs/VERIFICATION.md).
