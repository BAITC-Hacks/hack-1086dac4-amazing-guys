# Проверка frontend — 2026-09-23

- `npm run build`: успешно (TypeScript и production-сборка Vite).
- `PLAYWRIGHT_CHANNEL=chrome npm test`: **22 passed**, 28.7 секунды после совмещения с изменениями команды.
- Проверено прямое открытие каждого из пяти разделов с первого посещения без API-запросов;
  в режиме сервера без отчёта показано объяснение и явный переход к демопримеру.
- Проверены основной демосценарий, точность всех цитат, таблицы и фильтры,
  сохранение JSON, валидация файлов, неполное покрытие, сбой, пустой результат.
- HTTP-интеграция проверена на контролируемых ответах Playwright по r1:
  multipart, polling, URL источника, ошибочный формат, сетевой повтор с тем же
  ключом и новый ключ после фонового failed, безопасный вывод текста.
- axe: стартовый экран, обзор, документы, замечания, заключение и сравнение
  с открытым источником — без обнаруженных нарушений WCAG 2 A/AA и 2.1 AA.
  Автоматический аудит не заменяет полноценную ручную проверку доступности.
- Мобильный сценарий 390×844: меню, таблица, панель источников, отсутствие
  горизонтального переполнения страницы. Таблица имеет собственную прокрутку.
- Вручную просмотрены реальные снимки desktop и mobile; консоль браузера без ошибок.
- Обновление анимаций: короткие переходы разделов и вкладок, открытие и закрытие
  панели, подсветка текущей записи. Без новых зависимостей.
- Контролируемый медленный HTTP-ответ: скелетоны сменяются точными цитатами;
  ошибка убирает загрузку, повтор восстанавливает источники. Реальный сервер не вызывался.
- Проверены отмена устаревшего ответа и незавершённого закрытия при смене записи,
  возврат фокуса к последней записи, Tab/Shift+Tab на телефоне и отключение
  CSS/JS-анимаций при reduced motion. axe запускается после завершения переходов.
